# kurtz 0.9.7 — installer revision 2

The Mac installer now uses an expressive monochrome pug portrait inspired by the
owner's original kurtz branding sheet. The installation area sits beside the
portrait, with the exact kurtz wordmark, Sora and Electric Yellow accents.

The new package is `kurtz-0.9.7-macOS-universal-r2.dmg`. It contains the same
Developer-ID-signed, notarized and stapled universal **kurtz 0.9.7 (9)** app as
revision 1. This is an installer-artwork/layout update; no app executable or
resource is rebuilt or modified. The existing corresponding-source download
still describes the identical application.

Original installers and their checksums remain available. The portrait, exact
generation prompt, vector composition and Finder-layout scripts are retained
in the repository under `marketing/dmg` and `Tools`. The actual image is generated
with the built-in Imagegen tool; the source brand sheet remains unchanged.
